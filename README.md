Sum up 23 November's world news in one image: a one-page newspaper front page for Monday 23 November 2026, drawn in code with Pillow. Lead story: COP31 in Turkey ends with no deal after the longest climate talks on record, split over fossil-fuel phase-out and adaptation finance. Also on the page: a Ukrainian drone strike hits a Russian warship in Benghazi port, confirmed by Zelensky; Russian strikes kill at least 15 around Kyiv; a factory fire in Indonesia kills at least 24 with dozens missing; Nvidia brings back Jensen Huang as chief and the shares jump about 30%; BepiColombo enters orbit around Mercury after an eight-year journey; the NHS starts an AI breast-screening trial for nearly 700,000 women — plus eurozone inflation at 4.0%, the UK hosting the 2035 Women's World Cup, and an AI-assisted proof of the Riemann hypothesis.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program draws the page with Pillow and the system DejaVu fonts, needs no network, and writes the same bytes on every run to `entry.png` in the output directory.
